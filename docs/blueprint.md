# **App Name**: HangaHub Central

## Core Features:

- User Authentication: User authentication and management (login, registration, profile editing) via Firebase.
- Admin Dashboard: Admin dashboard for managing users, tasks, and groups, mirroring the FocusOS layout, built with Next.js and integrating Firebase data.
- Task Management: Task creation and assignment with custom categories (SOD, Embedded Systems, etc.) by admin, utilizing Firebase for data storage.
- Group Management: Group creation with various combinations defined by the admin, managed through Firebase.
- File Uploads: File uploads and storage managed using Appwrite with provided credentials (NEXT_PUBLIC_APPWRITE_PROJECT_ID and NEXT_PUBLIC_APPWRITE_ENDPOINT).
- Messaging System: Real-time messaging system using Firebase for communication between users and within groups.

## Style Guidelines:

- Primary color: A vibrant yellow (#FFC72C) to convey energy and collaboration.
- Background color: A light off-white (#F2F0EB) to create a clean and open space.
- Accent color: A contrasting teal (#46B1B1) to highlight important actions and notifications.
- Headline font: 'Space Grotesk' (sans-serif) for a modern and techy feel.
- Body font: 'Inter' (sans-serif) for a clean, readable interface. Recommended pairing with Space Grotesk for headers.
- Use clean and modern icons to represent different tasks, categories, and functionalities, similar to the FocusOS image provided.
- Maintain a clean, card-based layout similar to the FocusOS example, ensuring information is easily accessible and visually appealing.
